# libft

📚 libft - C Standard Library Re-implementation
C言語の標準ライブラリ関数をゼロから再実装し、自分専用のライブラリを構築するプロジェクトです。

42 Tokyo のカリキュラムにおいて、すべての後続プロジェクトの基盤となるライブラリです。既存の関数が「内部でどのようにメモリを操作しているか」を理解し、その挙動を完全に再現することを目的としています。

🎯 学習目標
[ ] 標準ライブラリ関数の仕様（POSIX等）の深い理解と完全な再現

[ ] ポインタ演算、バイト単位のメモリ操作の習得

[ ] 動的メモリ確保（malloc, free）によるメモリリークのない実装

[ ] 単方向連結リスト（Linked List）の構築と操作

🛠️ 使用技術
言語: C言語 (C99)

ビルドツール: Makefile (自作)

デバッグ: Valgrind (メモリリーク・メモリエラーの検知)

💡 実装内容と学習成果
1. メモリ・文字列操作 (Character/String Manipulation)
memset, bzero, memcpy, strlen などの基本的な操作を実装しました。

学び: 特に memcpy と memmove の違い（領域の重なり）の処理を通じて、メモリの連続性に関する理解が深まりました。

2. 堅牢な文字列コピーと連結 (Robust String Copy/Concatenation)
strlcpy や strlcat を実装しました。

学び: バッファオーバーランを防ぐための戻り値の設計や、ヌル終端の確実な処理など、安全なCプログラミングの基礎を学びました。

3. 動的メモリ確保による拡張関数 
ft_split や ft_strjoin など、複数の文字列を操作する関数を実装しました。

学び: 特に ft_split（文字列の分割）では、分割後の各文字列の確保と、途中で確保に失敗した際の「全メモリの遡り解放（Cleanup）」の実装に苦労しましたが、これにより完璧なメモリ管理能力が身につきました。

4. 連結リスト (Bonus: Linked List)
構造体を用いた単方向連結リストの操作（ノード追加、削除、マッピング）を実装しました。

学び: ポインタのポインタを扱う操作を通じて、メモリアドレスの概念がより抽象的に、かつ正確に理解できるようになりました。

🏃‍♂️ 実行方法
このライブラリは Makefile を用いてコンパイルします。

Bash
# ライブラリ(libft.a)の作成
make

# ボーナス(連結リスト関数)を含む作成
make bonus

# オブジェクトファイルの削除
make clean

# すべての生成ファイルを削除
make fclean
📝 学習メモ
苦労したポイント
エッジケースの処理: NULL ポインタが渡された際の挙動や、空文字列の処理など、標準関数がどう振る舞うべきかを一つずつ検証するのが大変でした。

Makefileの作成: 依存関係を正しく記述し、再リンク（Relink）が発生しない効率的なビルド環境を構築するのに試行錯誤しました。
