# 📚 libft - C標準ライブラリ関数の再実装

> C言語の標準ライブラリに含まれる主要な関数をゼロから自作し、自分専用のライブラリとして構築するプロジェクトです。

本プロジェクトは、すべての42プロジェクトの基盤となるライブラリです。既存の関数が内部でどのようにメモリを操作しているかを理解し、その挙動を忠実に再現することを目的としています。

## 🎯 技術的な達成目標
- [ ] 標準ライブラリ関数の仕様に基づいた、正確な挙動の再現。
- [ ] ポインタ演算およびバイト単位でのメモリ操作の習得。
- [ ] 動的メモリ確保（`malloc`, `free`）を用いた、メモリリークのない堅牢な実装。
- [ ] 単方向連結リスト（Linked List）の構築と操作。

## 📝 実装上のエピソード 1：ft_split におけるメモリ解放の徹底
複数の文字列を切り出す `ft_split` の実装では、メモリ管理の正確さが最も問われました。
途中でメモリ確保に失敗した場合、それまでに確保済みの領域をすべて遡って解放（Cleanup）するロジックを組み込みました。この「失敗時の後片付け」を徹底することで、どのような状況でもメモリを漏らさない堅牢なコードを書く習慣が身に付きました。

## 📝 実装上のエピソード 2：連結リストによる動的なデータ管理
ボーナス課題として取り組んだ連結リストの実装では、構造体とポインタを組み合わせたデータ管理を学びました。
データの追加、削除、検索といった基本操作をポインタの繋ぎ変えのみで実現するロジックを通じて、メモリ上のデータがどのようにリンクされ、保持されているのかを物理的にイメージできるようになりました。
