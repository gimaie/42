# 🎮 so_long - MiniLibXを用いた2Dタイルゲームの開発

> 簡易グラフィックライブラリ「MiniLibX」を使用し、マップデータの解析から描画、プレイヤーの操作までをゼロから実装した2Dゲームです。

本プロジェクトでは、2次元配列を用いたマップ情報の管理や、「プレイヤーが全てのアイテムを回収してゴールに到達できるか」というゲームの成立性を検証するロジックの実装に重点を置きました。

## 🎯 技術的な達成目標
* **マップのバリデーション**: 長方形の維持、壁による封鎖、および必須要素のチェック。
* **パスの有効性判定 (Flood Fill)**: 再帰アルゴリズムを用いて、物理的にクリア可能なマップであることを事前に検証。
* **イベント駆動の制御**: キーボード入力に応じたプレイヤーの移動と、画面の再描画。
* **リソース管理の徹底**: 画像データ（XPMファイル）やメモリの、正常時およびエラー時の確実な解放。

## 📝 実装上のエピソード 1：再帰の終了条件とマップコピーの活用
`flood_fill` を実行する際、元のマップデータを直接書き換えてしまうと本編で使用できなくなるため、検証専用にマップの「完全なコピー」を作成する構造にしました。
「データを壊さずに検証する」という、実用的なデータ操作の作法を学ぶ機会となりました。

## 📝 実装上のエピソード 2：グラフィックメモリの安全な解体手順
MiniLibX（MLX）を用いた画像処理では、C言語のメモリ管理に加え、グラフィックサーバー側のリソース解放も必要になります。
`cleanup_game` 関数では、各画像ポインタが確保されているかを確認してから破棄する「防御的な設計」を行い、1バイトのリークも許さない堅牢な終了処理を実現しました。
