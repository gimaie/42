# 🖋️ ft_printf - 可変長引数処理と書式指定子の再実装

> `unistd.h` の `write` システムコールと `stdarg.h` のマクロを組み合わせ、標準関数 `printf` の挙動を再現するプロジェクトです。

スタックメモリ上に配置された不定数の引数を、書式指定子に基づいた適切な型で取得し、文字列変換を経て標準出力へ書き出す一連の処理を構築しました。

## 🎯 技術的な達成目標
- [ ] **可変長引数 (Variadic Arguments)** の制御と、スタック上の引数ポインタの走査。
- [ ] **書式指定子の解析**: `%` に続く文字を判定し、適切な変換関数へ分岐させるロジックの実装。
- [ ] **基数変換の自作**: 10進数、16進数、およびポインタアドレス用の文字列変換処理の構築。
- [ ] **正確な出力カウント**: すべての `write` 実行結果を累積し、最終的な出力合計値を算出する設計。

## 📝 実装上のエピソード 1：エラー伝播と累積カウントの整合性
`ft_printf` では、出力した全バイト数を正確に返す必要があります。
単純に累計を加算するだけでは、途中で `write` システムコールが失敗して `-1` を返した場合にエラーを正しく検知できません。そのため、各階層での戻り値を毎回検証し、負の値が返された瞬間に処理を中断して即座に `-1` を親関数へ伝播させるロジックを徹底しました。

## 📝 実装上のエピソード 2：stdarg.h のマクロによる引数の取得
引数の個数が動的に変わる処理を実装するため、`va_list` などのマクロを活用しました。
サブ関数に `va_list` のアドレスを渡すことで、関数を跨いでも「いまどこまで引数を読み込んだか」という状態を共有できる設計にしました。この実装を通じて、関数呼び出し時にデータがメモリ（スタック）にどう積まれているのかを具体的に理解できました。
